🧠 Concepts-Clés

Terme Signification
État Configuration actuelle du puzzle (position des tuiles)
Action Un mouvement — glisser une tuile dans la case vide
Récompense Retour : +1 quand l'état suivant est l'objectif, 0 sinon (pénalité par pas optionnelle)
Valeur Q Qualité estimée d'une action depuis un état (apprise)
Épisode Une tentative complète de résolution
Politique La stratégie de l'agente : quelle action choisir dans chaque état
💡 Formule du Q-learning :
Q(s,a) ← Q(s,a) + α × [r + γ × max Q(s') − Q(s,a)]

⚙️ Paramètres d'Entraînement

Paramètre Effet Valeurs utiles
Taux d'apprentissage (α) Vitesse de mise à jour des valeurs Q 0,3 – 0,7
Escompte (γ) Importance des récompenses futures vs immédiates 0,9 – 0,99
Epsilon (ε) Probabilité d'exploration aléatoire 0,2 – 0,4

Conseils sur les paramètres

  • α élevé : apprend vite mais peut être instable
  • γ élevé : planifie à long terme (idéal pour les puzzles !)
  • ε élevé : plus d'exploration, convergence plus lente
  • Pour tester : régler ε = 0 (stratégie purement gloutonne — l'agente n'explore plus)

Référence Bk = un état de départ à k coups de l'objectif.

🏆 Nombre de Dieu = diamètre du graphe des états accessibles : nombre de coups pour résoudre le pire état de départ si l'on joue parfaitement.

🚀 Déroulé d'Entraînement

Pas à pas

  1. Régler les paramètres : α=0,5, γ=0,9, ε=0,3
  2. Entraîner : cliquer plusieurs fois sur « Entraîner 100 »
  3. Observer la table Q : les couleurs apparaissent à mesure que l'agente apprend
  4. Charger une référence : essayer B1, B2, B3…
  5. Tester : cliquer « Résoudre (glouton) »
  6. Comparer : mouvements vs minimum théorique
  7. Ajuster : modifier les paramètres, entraîner davantage
  8. Défi : atteindrez-vous le Nombre de Dieu ?

En cas de problème

  • L'agente ne trouve pas la solution ? Entraîner davantage (1000+ épisodes)
  • Table Q vide ? Vérifier que α ≠ 0
  • Trop lent ? Réduire ε après l'entraînement
